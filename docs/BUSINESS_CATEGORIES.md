# Категории бизнеса

Каталог хранится в `leasefit/business.py`. Код подкатегории сохраняется в запросе независимо от свободного рабочего названия. Уже созданный запрос можно настроить через «Категория и шаблон требований». При создании запрос открывает этот экран по кнопке «Далее: выбрать бизнес».

| Категория | Подкатегории и стабильные коды |
| --- | --- |
| Общественное питание | Кофейня навынос `food.coffee_to_go`, кофейня с посадочными местами `food.coffee_seating`, кафе без полного цикла `food.cafe_limited`, кафе с кухней `food.cafe_kitchen`, пекарня `food.bakery` |
| Пункты выдачи | Стандартный `pickup.standard`, большая зона хранения `pickup.storage`, крупногабаритные товары `pickup.oversize` |
| Розничная торговля | Продуктовая `retail.grocery`, непродовольственная `retail.nonfood`, специализированная `retail.specialized` |
| Услуги | Салон красоты `services.beauty`, парикмахерская `services.hair`, ремонтная мастерская `services.repair` |
| Офисы | С приёмом клиентов `office.clients`, без приёма `office.internal` |
| Другое | Индивидуальный профиль `other.individual` |

В общепите вопросы охватывают приготовление, горячую кухню, посадку, выпечку, оборудование, хранение, приёмку и технологическую потребность в отдельной вытяжке. В ПВЗ уточняются клиенты, хранение, крупногабаритные товары и зона разгрузки. Для всех подкатегорий доступны способ доступа клиентов, рабочий график и разгрузка.

Шаблон сначала показывает недостающие рекомендации. Подтверждённый предварительный просмотр привязан к версии запроса. Смена категории при существующих требованиях требует явного подтверждения. Существующие требования имеют приоритет. Повторное применение сохраняет количество требований и версию профиля, если состав и ответы прежние.

Новые рекомендации имеют желательную важность и источник вида `food.cafe_kitchen@1`. Их можно изменить в профиле. Самостоятельные условия имеют источник `client`. Оборудование фиксируется как ввод клиента для последующей инженерной оценки. Числовые нормы и пороги потребления из ответа об оборудовании не выводятся. Нормативные проверки описаны отдельно. [Нормативный реестр](REGULATORY_REQUIREMENTS.md).
