# Metrapi в LeaseFIT

Руководитель и администратор открывают раздел «Парсинг» (`/app/parser`). Вставьте прямую ссылку Авито, Циан, Домклик или Яндекс Недвижимости либо найдите варианты по городу, тексту или адресу и диапазону площади. Поиск показывает до 20 объявлений. Предпросмотр позволяет проверить источник и цену. Кнопка «Добавить в каталог» сохраняет самостоятельную карточку активного агентства. Если площадка и ID или ссылка уже есть в его каталоге, предпросмотр предлагает открыть эту карточку. Повторная отправка формы тоже открывает существующую карточку и сохраняет ручные правки.

## Локальный запуск

Для поиска достаточно локального LeaseFIT. Веб-контейнеру нужен исходящий HTTPS-доступ к `api.metrapi.ru`. Добавьте строку `METRAPI_API_KEY=ваш_ключ` в локальный файл окружения нужного запуска.

| Запуск | Файл окружения | Команда из корня репозитория | Адрес по умолчанию |
|---|---|---|---|
| Основной | `.env` | `docker compose up -d --build` | `http://localhost:8000/app/parser` |
| Демо Новосибирска | `.env.showcase` | `docker compose --env-file .env.showcase -f compose.showcase.yaml up -d --build` | `http://localhost:8001/app/parser` |

После изменения файла окружения используйте указанную команду `up`. Команда `restart` сохраняет прежнее окружение контейнера. Если в кабинете нет пункта «Парсинг», проверьте, что вошли под действующим руководителем. В основной учебной базе это `leader@example.invalid`.

## Источники и импорт

Для поиска используется официальный `GET /v1/items`, для прямой ссылки — `GET /v1/item/{source}/{source_id}`. Сервис извлекает ID из ссылки и запрашивает его только у Metrapi. Сокращённые ссылки нужно раскрыть в браузере. Ключ передаётся только сервером в заголовке `X-Api-Key`. Поиск не обращается к самим площадкам и не запускается в фоне. Исходный ответ API, имена продавцов, телефоны, полные описания и фотографии не сохраняются. Из описания извлекается явно указанная мощность в кВт. Диапазоны, фразы о возможном увеличении и несовпадающие распознанные значения остаются на ручное уточнение.

## Что возвращает API

28 ноября 2026 года выполнен запрос на 20 объявлений коммерческой аренды в Новосибирске. Ответ HTTP 200. Авито — 12, Циан — 5, Домклик — 2, Яндекс Недвижимость — 1. Количество в таблице означает число непустых значений в этой выборке. Наличие поля в схеме или значение в объявлении само по себе не подтверждает характеристику.

| Данные Metrapi | Заполнено | Уже есть в LeaseFIT | Что делает импорт |
|---|---:|---|---|
| `address`, `title`, `url` | 20/20 каждое | Адрес или рабочая метка, ссылка | Заполняет адрес и ссылку. Заголовок используется как запасная метка |
| `source`, `source_id` | 20/20 каждое | Источник есть. Отдельных колонок внешнего ID и площадки нет | Записывает источник, использует пару для защиты от повторного импорта |
| `published_at`, `updated_at`, `first_seen`, `last_seen` | 20/20 каждое | Есть дата источника. Отдельных дат жизненного цикла объявления нет | Заполняет дату источника по обновлению или публикации |
| `area_total`, `floor` | 20/20 каждое | Площадь, этаж и одноимённые характеристики | Заполняет карточку и добавляет непроверенные наблюдения |
| `commercial_types`, `deal_type`, `realty_type` | 20/20 каждое | В карточке один тип помещения. Отдельного списка назначений нет | Выбирает поддерживаемый тип для коммерческой аренды |
| `price`, `price_period`, `price_unit` | 20/20, 12/20, 4/20 | Базовая аренда в месяц и ставка за м² в месяц | Учитывает единицу и период. Годовую цену делит на 12. Неясный период для ставки оставляет на уточнение |
| `price_per_sqm`, `src_price_sqm` | 16/20, 11/20 | Есть ставка за м² в месяц | Рассчитывает цену из исходной суммы с её единицей и периодом. Расчётная ставка Metrapi для коммерческой аренды может быть годовой |
| `deposit`, `commission` | 15/20, 7/20 | Есть суммы в рублях | Переносит явные рублёвые суммы и «без залога/комиссии». Проценты показывает для ручной проверки |
| `tax_form`, `lease_type`, `rent_period`, `prepayment` | 5/20, 16/20, 18/20, 0/20 | Есть режим/ставка НДС и текст общих условий. Отдельных полей типа и срока договора, предоплаты нет | Заполняет только явно указанный режим НДС. Процент НДС остаётся пустым. Тип договора виден в предпросмотре |
| `ceiling_height`, `entrance_type` | 13/20, 1/20 | Высота потолка и отдельный вход | Записывает как непроверенные сведения. «Общий вход» означает отсутствие отдельного |
| `heating`, `parking` | 12/20, 3/20 | Есть характеристики отопления и парковки | Показывает для проверки применимости к помещению |
| `water_supply`, `sewerage`, `electricity` | 0/20 каждое | Есть вода, канализация и мощность в кВт | Не заполняет. Наличие электричества само по себе не задаёт мощность |
| Мощность в кВт | Отдельного поля API нет. Из описаний распознано 10/20 в проверочной выборке | Есть характеристика мощности в кВт | Добавляет наблюдение «Не подтверждено» с источником «Объявление». Оно требует проверки и не даёт положительного технического заключения |
| Вентиляция, вытяжка, трёхфазное питание, мокрые точки | Нет отдельных полей в схеме или ответе | Есть технические характеристики | Риелтор уточняет по собственнику или документам |
| `description`, `photos` | 20/20 каждое | Нет описания объявления и галереи. Закрытые документы — отдельная функция | Не сохраняет |
| `locality`, `region`, `district`, `lat`, `lon`, `metro`, `metro_minutes` | 20/20, 20/20, 5/20, 20/20, 20/20, 18/20, 17/20 | У помещения есть город и район. Отдельных полей региона, координат и метро нет | Импортирует город из `locality` и район из `district`. Местоположение остаётся неподтверждённым |
| `commercial_building_type`, `commercial_layout`, `business_center`, `floors_total` | 3/20, 1/20, 1/20, 8/20 | Отдельных полей здания, планировки и этажности нет | Показывает тип здания и планировку в предпросмотре |
| `seller_name`, `seller_company`, `phone`, `phones` | 15/20, 7/20, 5/20, 3/20 | Контактов источника в карточке помещения нет | Не показывает и не сохраняет личные контакты |
| `group_id`, `group_spread_m` | 20/20, 11/20 | Полей группы дублей нет | Карточки разных площадок автоматически не объединяются |
| Эксплуатация, коммунальные в рублях, ремонт клиента, лимит клиента | Нет структурированных сумм в выборке | Есть в карточке или запросе | Сохраняет неизвестность. Лимит и клиентские допущения остаются в запросе |

Поля `business_center`, `build_year`, `elevators`, `house_type`, `jk`, `renovation`, `amenities`, `railway`, `railway_km` тоже встречались в выборке. Они не переносятся. В частности, год и этажность здания не описывают характеристики отдельного помещения.

[Документация Metrapi](https://metrapi.ru/api-docs.html). [Условия доступа к данным](https://metrapi.ru/offer.html).

Живые запросы карточки успешно проверены для всех четырёх поддерживаемых площадок. В повторной выборке из 20 коммерческих объявлений Новосибирска распознано 10 однозначных упоминаний мощности, город пришёл у всех, район — у пяти. Эти числа описывают только проверочную выборку.
