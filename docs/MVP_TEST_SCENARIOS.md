# Новосибирск · воспроизводимая приёмка

Запускайте команду только в отдельной временной базе, с `DEBUG=1` и применёнными миграциями.

```sh
python manage.py seed_novosibirsk --disposable-db
python manage.py test leasefit.test_expanded_mvp
```

Данные и названия источников вымышлены. Набор создаёт отдельное агентство и три профиля с одним каталогом.

Для ручного входа в учебную базу можно назначить пароль одноимённой учётной записи командой `python manage.py changepassword novosibirsk-fixture@example.invalid`. Автоматические тесты используют тестовую сессию.

| Помещение | Подтверждённые факты | Неизвестное или требующее уточнения |
| --- | --- | --- |
| A, Ленинский | 60 м², 15 кВт, вода, отдельный вход, отсутствие отдельной вытяжки | Канал разгрузки |
| B, Центральный | 60 м², 30 кВт, вода, отдельный вход | Вентиляция заявлена без подтверждения |
| C, Октябрьский | 60 м², 25 кВт, вода, отдельный вход | Вентиляция и режим работы |

Для A ожидаются соответствие по обязательным условиям кофейни навынос, блокер у кафе с кухней, уточнение у ПВЗ. Пороги мощности — тестовые требования клиента. Автотест проверяет общий ID объекта, сохранение ручного требования при смене подкатегории, источник шаблона и отсутствие дублей при повторном применении.

Для кофейни с A расчёт по учебным данным даёт 677 операций в месяц / 28 в день, сценарный предел аренды 157 000 ₽, долю расходов 14,60 %, потребность на открытие 230 000 ₽ и результат 37 000 ₽/мес. при снижении продаж на 20 %. Тест покрывает пропуски, нулевые затраты, неположительную маржу, историю и неизменность сохранённых PDF после изменения допущений.

Браузерный сценарий `scripts/browser_smoke.py` использует свежую учебную ссылку из отдельной базы (`python manage.py seed_demo --fresh-invitation`). Он проходит каталог, подтверждение графика через полночь, предварительный просмотр и применение шаблона, нормативный блок, финансовый сценарий, ранжирование, сравнение, отсоединение и скачивание исходного PDF. Полная проверка оценивает 1440, 768 и 390 px.
