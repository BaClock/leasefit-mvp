# Демонстрационная база LeaseFIT для Новосибирска

В наборе 20 помещений в 10 районах, 12 профилей, 255 наблюдений и 70 клиентских требований. Адресные метки, платежи, характеристики и подтверждения вымышлены. Это учебные данные, которые нельзя использовать как объявления, коммерческие предложения, технические паспорта или нормативное заключение.

Исходный файл [novosibirsk_demo_20x12.json](../tests/data/novosibirsk_demo_20x12.json) хранит наблюдения, условия клиента, бизнес-анкету, план расходов и 13 контрольных пар. Команда использует стабильные ключи из `NSK-P…` и `NSK-B…`. Импорт выполняется одной транзакцией. Повторный запуск обновляет поля набора и сохраняет идентификаторы, пароль и уже сделанный вручную выбор. Команда выводит числа созданных и обновлённых записей.

## Запуск на Windows

Из корня репозитория один раз создайте локальный файл окружения. Сохраните его для перезапусков.

```powershell
if (-not (Test-Path -LiteralPath '.env.showcase')) {
    $db = [Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(32)).ToLowerInvariant()
    $key = [Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(48)).ToLowerInvariant()
    @("LEASEFIT_DEMO_DB_PASSWORD=$db", "LEASEFIT_DEMO_SECRET_KEY=$key") |
        Set-Content -LiteralPath '.env.showcase' -Encoding utf8NoBOM
}
docker compose --env-file .env.showcase -f compose.showcase.yaml up -d --build --wait
docker compose --env-file .env.showcase -f compose.showcase.yaml exec web python manage.py seed_novosibirsk_showcase --disposable-db
docker compose --env-file .env.showcase -f compose.showcase.yaml exec web python manage.py changepassword novosibirsk-showcase@example.invalid
```

Команды генерации используют PowerShell 7. Compose включает отдельную базу PostgreSQL `leasefit_showcase` и отдельный том проекта `leasefit-showcase`. Импорт также требует `DEBUG=1`, `LEASEFIT_SHOWCASE=1` и `--disposable-db`. Демо доступно локально по [127.0.0.1:8001/login](http://127.0.0.1:8001/login). Логин `novosibirsk-showcase@example.invalid`. Задайте пароль в интерактивном запросе `changepassword`. При первом импорте вход по паролю выключен.

Для парсинга в демо добавьте `METRAPI_API_KEY` в `.env.showcase` и снова запустите `docker compose --env-file .env.showcase -f compose.showcase.yaml up -d --build`. Импортированные объявления сохраняются в каталоге демо. [Подключение Metrapi](METRAPI.md#локальный-запуск).

Чтобы **сбросить только демо**, выполните `docker compose --env-file .env.showcase -f compose.showcase.yaml down --volumes` и повторите запуск, импорт и установку пароля. Эта команда удаляет том указанного демонстрационного проекта вместе с созданными в нём отчётами и правками. Для обычной остановки используйте `down` без `--volumes`.

## Что проверить

- В «Запросах» откройте «ДЕМО Кофейня навынос» → «Помещения». Каталог показывает все 20 карточек по группам. Раздел выбранных помещений изначально пуст. Неподтверждённые характеристики и неизвестные значения видны в причинах оценки.
- Для кофейни навынос P01 соответствует техническим условиям, P03 отклоняется из-за канализации, для P19 нужно уточнить мощность и инженерные условия. Для кофейни с посадкой P05 требует подтверждения вентиляции. Для кафе с кухней P16 проходит, а у P02 недостаточно мощности. У крупногабаритного ПВЗ P18 проходит, а у P04 доступ ограничен. Для салона проходит P09, для офиса без приёма клиентов — P17.
- Сравните P16 в профилях кафе с кухней, кофейни, пекарни и продуктового магазина. Оценки используют одну общую карточку. Технический статус определяется обязательными условиями. Бюджет, нормативные вопросы и технический статус показаны отдельно.
- Добавьте P01 и P02 из рекомендаций к сравнению кофейни навынос. Пересчитайте результаты, проверьте доступную базовую аренду, месячную нагрузку, точку безубыточности и сценарии снижения продаж. У P01 месячная нагрузка составляет 123 000 ₽ при лимите 115 000 ₽. Точка безубыточности составляет 1 103 операции в месяц. Для ПВЗ среднее значение на операцию означает вознаграждение за выдачу.
- Разовые расходы требуют заполнения финансовых условий выбранного объекта. При вводе адаптации 40 000 ₽, оборудования 60 000 ₽, закупок 20 000 ₽, резерва 50 000 ₽ и нулевых прочих расходов расчёт для P01 составляет 280 000 ₽. Сформируйте PDF, затем уберите P01 из сравнения и проверьте, что карточка остаётся в каталоге.

Синтетические наблюдения имеют явную пометку в источнике. Для `null` создаётся наблюдение без значения со статусом «Неизвестно». Поля из `unverified_specs` имеют статус «Не подтверждено». Коммерческие суммы тоже заданы как неподтверждённые учебные данные. При неполных расходах показывается известный подытог. Набор не моделирует трафик, конкурентов или вероятность успеха.

Регрессионные тесты `python manage.py test leasefit.test_novosibirsk_showcase` проверяют все 13 пар, изоляцию, повторный импорт и сравнение. Для браузерной приёмки используйте `scripts/browser_showcase.py` с Playwright, URL отдельной проверочной копии, ID запроса кофейни навынос и временным паролем в `LEASEFIT_BROWSER_PASSWORD`. Сценарий создаёт связи и PDF, поэтому запускайте его в свежей проверочной копии.
