## Браузер

В общем Chrome/Chromium вручную проверены вход в учебный кабинет, профиль кофейни, сравнение трёх вариантов в режиме различий, предпросмотр, выпуск и скачивание `LeaseFIT-v1.pdf`. Chrome показал завершённую загрузку.

Отдельный Playwright-сценарий `scripts/browser_smoke.py` выполнен на финальном контейнере через настоящий HTTP:

**PASS:** новое приглашение → установка пароля → создание профиля → два новых помещения → сведения 15/12 кВт → пересчёт → сравнение → предпросмотр → выпуск → скачивание PDF.

На **1440, 768 и 390 px** проверены профиль и сравнение: нет горизонтального переполнения всей страницы, блокер виден. До 768 px используются карточки сравнения. Ошибок JavaScript нет. Созданы скриншоты `artifacts/profile-*.png`, `artifacts/compare-*.png` и `artifacts/LeaseFIT-browser-example.pdf`; они не коммитятся как исходный код.

PDF открыт/отрендерен для визуальной проверки; кириллица читается, заголовки и подвал не перекрывают содержимое. Финальный браузерный PDF на два варианта — 2 страницы, содержит локальное время Новосибирска UTC+7, технические статусы и предупреждение о бюджете.

6. Затем выполнен повторный расчёт вариантов старого запроса; SHA-256 ранее выпущенного PDF остался прежним.
