Как считается балл

За подтверждённое выполнение обязательного параметра начисляются 3 балла, желательного — 1 балл. Полные месячные расходы в пределах заданного бюджета дают ещё 2 балла. Сумма делится на максимум и переводится в шкалу от 0 до 100.

Невыполненные и неподтверждённые условия дают 0 баллов. Каждый параметр учитывается один раз. Если по нему есть несколько условий, приоритет у обязательных, и должны выполняться все условия учитываемой важности. Без месячного лимита бюджет исключается из расчёта.

Статус определяют обязательные требования. Рейтинг сортируется сначала по статусу, затем по баллу. Когда нет ни одной подтверждённой технической проверки, балл не рассчитывается.
